Keep your Mac awake for AI agents, even with the lid closed.

Keepwatch is a menu-bar app for people who run Claude Code, Codex and other coding agents for hours. Your Mac stays awake exactly while they work. Close the lid and it keeps going, then goes back to sleep on schedule. It also keeps watch on your mic and camera.

Everything a laptop developer reaches for, in one menu

No more choosing between a sleeping Mac that kills a three-hour agent run and a Mac left awake all night in your bag.

Awake while agents run

Detects Claude Code, Codex, Gemini CLI, Aider, OpenCode, Goose, Amp and more. Sleeps normally two minutes after the last one exits, and tells you when an agent finishes.

Lid-closed sessions

Keep working with the lid shut, then sleep three hours after the lid closes, at 1:00, or when agents finish. One password per session; a watchdog ends it even if the app quits.

Safe by default

Lid sessions run only on power unless you allow battery (then they stop at 20%). Thermal cut-out, 12-hour cap, and a check on every launch that sleep wasn't left off.

Mic and camera watch

Live indicators in the menu bar, which app is using your microphone, one-click mute, and mute when the lid closes. Keepwatch itself never records anything.

Battery and power

Battery health as a percentage of original capacity, cycle count, time left, Low Power Mode, thermal state, and who else is keeping your Mac awake.

Developer extras

See which of your processes are listening on which ports, and stop one with a confirmation. One-click Dock and Finder toggles, and links to every privacy pane.

A command line your agents can use

Install the keepwatch command from the dashboard. Agents get stable JSON and exit codes, and they can never start a lid session: that always needs your password.

Add the agent skill so Claude Code and Codex know when to use it: npx skills add AgentSkillDeck/keepwatch

# stay awake exactly while a command runs
$ keepwatch run -- npm test

# stay awake while any agent CLI runs
$ keepwatch awake --agents

# power, sleep blockers, agents, mic/camera
$ keepwatch status --json

# what's on :3000?
$ keepwatch ports

Questions

Can a MacBook keep running with the lid closed without an external display?

Not by default: closing the lid sleeps the Mac unless an external display, power and keyboard are attached. Keepwatch runs a lid-closed session: you enter your password once, it turns sleep off, and a small watchdog turns sleep back on and puts the Mac to sleep after the time you chose, at a set time, when your agents finish, or if the battery gets low.

How do I keep my Mac awake while Claude Code or Codex is running?

Turn on “While AI agents run” in Keepwatch, or run keepwatch awake --agents. The Mac stays awake while agent CLIs run, then sleeps normally two minutes after the last one exits. Agents can also wrap a single command with keepwatch run -- <command>.

Is it safe to keep a MacBook awake with the lid closed in a bag?

Heat in a closed bag is the main risk, so Keepwatch only runs lid-closed sessions on power by default, ends them on serious thermal pressure or low battery, caps every session at 12 hours, and checks on every launch that sleep was not left off.

How is Keepwatch different from caffeinate or Amphetamine?

caffeinate can't keep a Mac awake with the lid closed, and Amphetamine needs a separate helper for that. Keepwatch is built for AI agents: it knows when agent CLIs are running, ends lid sessions on its own, adds mic and camera indicators, and ships a CLI with JSON output that agents can call. It's free and open source under Apache-2.0.

Does Keepwatch need microphone or camera permission?

No. It never records anything; it only asks macOS whether the microphone or camera is running. It needs no Full Disk Access, Accessibility or Screen Recording permission and makes no network requests.

Lid-closed sessions are in beta. Read exactly what runs with administrator rights in SECURITY.md.
