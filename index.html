Open plugins and skills for coding agents. Design interfaces that look like your product, and make finished multi-voice audio on your own machine.

Install in two commandsView on GitHub

Install

Add the marketplace once inside Claude Code, then install the plugins you want.

# add the deck
/plugin marketplace add AgentSkillDeck/agentskilldeck
# pick your plugins
/plugin install ui@agentskilldeck
/plugin install audio@agentskilldeck

Or install a single skill with the skills CLI: npx skills add AgentSkillDeck/agentskilldeck --skill deck-design. Needs Node 18+; audio also needs Python 3.10+ and ffmpeg.

Seven skills, two plugins

Every skill is plain Markdown plus small dependency-free scripts. No account, no server, no telemetry.
